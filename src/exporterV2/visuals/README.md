# Mesh generators

Every mesh in the exported plant is generated by code. This page is the map:
where each generator lives and which `config/visuals.yaml` switch drives it.
Physics never depends on these meshes; colliders are simple capsules built in
`core/usd/`.

| Part of the plant | Generator | Code | Switches in `config/visuals.yaml` |
| --- | --- | --- | --- |
| Stems, side shoots, petioles, leaf rachis, truss rachis, pedicels | Organic swept tube, one mesh per rigid link (a branch welded by fixed joints, such as the default stem, gets one continuous mesh): taper, smooth radius changes, root flare, junction bulge | `core/skinning/visual_segmented.py` (`author_segmented_visual_axis`), shape maths in `core/skinning/mesh.py` (`_visual_radius`, `build_axis_tube_data`), defaults in `core/skinning/model.py` (`VisualProfile`) | `quality`, `stems.junction_bulge` |
| Decorative twig at a branch tip that ends in a leaf | Small curved shoot plus a tiny leaf | `core/skinning/terminal_fork.py` (`author_terminal_visual_forks`) | `stems.terminal_forks` |
| Leaflet stalk (petiolule) | Same organic tube as the stems | `visuals/leaves.py` (`author_leaf_visuals`) | `pose` |
| Leaflet blade, `baked` (default) | Reference to a pre-generated 3D leaflet (outline, bend, veins) in `assets/leaves/`, tipped down by the droop angle | `leaf_shapes/baked.py`, placement in `visuals/leaves.py` (`baked_blade_frame`, `blade_tilt`) | `leaves.generator`, `leaves.seed`, `leaves.one_per_leaflet`, `leaves.baked_set`, `leaves.droop_deg`, `leaves.droop_jitter_deg`, `leaves.roll_jitter_deg` |
| Leaflet blade, `simple` | Procedural blade: width profile, fold, arch, gravity sag | `core/skinning/leaf_blade.py` (`author_leaf_blade`) | `leaves.generator: simple` |
| Stem colour | One colour and the shared stem material on every stem, petiole, rachis, petiolule, pedicel and fork twig | `visuals/stems.py` (`apply_stem_color`) | `stems.color` |
| Truss rachis colour | Truss material on the organic mesh (overridden by `stems.color` unless it is `null`) | `visuals/trusses.py` | none |
| Pedicel curve | Curved "gravity elbow" tube replacing the straight pedicel mesh | `core/usd/pedicel_geometry.py` (`create_gravity_elbow_mesh`), applied by `visuals/trusses.py` | `pedicels.gravity_curve` |
| Tomato | Sphere coloured by ripeness | `core/usd/terminal_bodies.py` (`build_terminal_bodies`) | `fruits.generator` (only `sphere`), `fruits.size_scale` (drawn size only; mass keeps the skeleton radius) |
| Tomato calyx (decoration) | Five small sepals facing the pedicel, no collider | `visuals/fruits.py` (`author_calyces`) | `fruits.calyx` |
| Materials | Shared PBR materials for leaves, stems, truss and 8 ripeness buckets for tomatoes | `core/usd/materials.py` | none |

The orchestration (which generator runs for which part) is in
`exporter.py`; the per-link visual settings come from `skeleton_branches.py`
(`_visual_profile`).

## Changing a look

- **Thicker or thinner junctions, taper, ring density:** edit the defaults of
  `VisualProfile` in `core/skinning/model.py`; `quality: performance` already
  lowers the ring and radial counts.
- **Different leaflet shape:** switch `leaves.generator` or `leaves.seed`,
  bake another set (`src/exporterV2/docs/11_baked_leaf_assets.md`), or change
  `core/skinning/leaf_blade.py` for the `simple` blade.
- **Leaflets more or less droopy:** `leaves.droop_deg` and its jitters.
- **Stem colour:** `stems.color` (linear RGB), `null` for the lighter default.
- **Different tomato colour:** `_tomato_color` in `core/usd/materials.py`.
- **A new fruit shape:** add a value to `fruits.generator` in `config.py`
  (`_VISUALS_CHOICES`) and branch on it where `terminal_bodies.py` authors the
  sphere (`create_sphere_rigid_body` in `core/usd/geometry.py`).

After a change, run `./run_main.sh --generate-only` and open
`output/plant.usda`, then the visual tests:

```bash
uv run pytest -q src/exporterV2/tests/test_exporter.py src/exporterV2/core/skinning/tests
```
